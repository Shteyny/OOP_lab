### 1. `access_levels_demo.cpp` - PRIVATE, PROTECTED, PUBLIC
**Что изучаем:** Уровни доступности членов класса

```cpp
class Person {
private:      // Только в классе
    string ssn;
    
protected:    // В классе и в наследниках
    string name;
    
public:       // Везде
    string department;
};
```

**Таблица прав доступа:**
| Область | PRIVATE | PROTECTED | PUBLIC |
|---------|---------|-----------|--------|
| Внутри класса | ✓ | ✓ | ✓ |
| В наследнике | ✗ | ✓ | ✓ |
| Снаружи | ✗ | ✗ | ✓ |

**Примеры в файле:**
- Обращение к разным полям
- Инкапсуляция (private данные + public методы для доступа)
- Использование protected полей в наследниках
- Практические ошибки и их исправление

**Запуск:**
```bash
g++ -o access_levels access_levels_demo.cpp
./access_levels
```

### 2. `01_static_and_dynamic.cpp` - Статические и динамические объекты
**Что изучаем:** Создание объектов в стеке и в куче

```cpp
// СТАТИЧЕСКИЙ (в стеке)
Point p1;                    // Автоматическое удаление
Point p2(3.5, 4.2);        // С параметрами

// ДИНАМИЧЕСКИЙ (в куче)
Point *p3 = new Point();    // Ручное управление
Point *p4 = new Point(7.5, 8.9);
delete p3;                  // НУЖНО удалить!
delete p4;
```

**Ключевые различия:**

| Характеристика | Статический | Динамический |
|---|---|---|
| Синтаксис | `Point p;` | `Point *p = new Point();` |
| Память | Стек | Куча |
| Время жизни | До конца блока (автоматически) | Пока не delete (ручная) |
| Обращение | `p.method()` | `p->method()` |
| Удаление | Автоматически | `delete p;` |
| Адрес | `&p` | `p` (сам указатель) |

**Примеры в файле:**
- Создание в стеке и куче
- Обращение к полям (оператор `.` и `->`)
- Адреса в памяти
- Удаление динамических объектов
- Автоматическое удаление статических

**Запуск:**
```bash
g++ -o static_dynamic 01_static_and_dynamic.cpp
./static_dynamic
```

### 3. `02_constructors_destructors.cpp` - Конструкторы и деструкторы
**Что изучаем:** Жизненный цикл объектов

```cpp
class Circle {
public:
    Circle()                 // Конструктор БЕЗ параметров
    Circle(double r)         // Конструктор С параметрами
    Circle(const Circle& other)  // Конструктор копирования
    ~Circle()                // Деструктор
};
```

**Порядок вызова:**
1. **При создании:**
   - Выделяется память
   - Вызывается конструктор
   
2. **При копировании:**
   - Автоматически вызывается конструктор копирования
   - `Circle c2 = c1;`
   
3. **При удалении:**
   - Вызывается деструктор
   - Освобождается память

**Примеры в файле:**
- Конструктор без параметров (инициализация по умолчанию)
- Конструктор с параметрами (инициализация с значениями)
- Конструктор копирования (копирование объекта)
- Отладочный вывод во всех конструкторах и деструкторе
- Порядок вызова при статических и динамических объектах
- Локальные объекты в блоках

**Запуск:**
```bash
g++ -o constructors 02_constructors_destructors.cpp
./constructors
```

**Важно:** Смотрите отладочный вывод и выясняйте, когда и в каком порядке вызываются конструкторы и деструкторы!

### 4. `03_inheritance.cpp` - Наследование и иерархия классов
**Что изучаем:** Создание классов-наследников, порядок вызова конструкторов/деструкторов

```cpp
class Shape {
public:
    Shape() { ... }              // Конструктор базового класса
    ~Shape() { ... }
};

class Rectangle : public Shape {
public:
    Rectangle() : Shape() { ... }  // Вызов конструктора базового класса
    ~Rectangle() { ... }
};
```

**Порядок вызова конструкторов (создание):**
1. Конструктор базового класса Shape
2. Конструктор наследника Rectangle

**Порядок вызова деструкторов (удаление):**
1. Деструктор наследника Rectangle
2. Деструктор базового класса Shape

**Примеры в файле:**
- Объект базового класса
- Объект наследника (конструктор и деструктор)
- Наследник БЕЗ конструктора/деструктора (использует базовый)
- Указатель базового класса на объект наследника
- Срезание объекта (Shape s = rectangle; - ОПАСНО!)
- Порядок вызова конструкторов/деструкторов в разных сценариях

**Запуск:**
```bash
g++ -o inheritance 03_inheritance.cpp
./inheritance
```

### 5. `04_composition.cpp` - Композиция объектов
**Что изучаем:** Объект класса как часть другого класса

#### Композиция с объектом (не указатель):
```cpp
class Circle_WithObject {
private:
    Point center;      // Объект (НЕ указатель)
    Color color;
public:
    Circle_WithObject(double x, double y, string c)
        : center(x, y), color(c) { }  // СПИСОК ИНИЦИАЛИЗАЦИИ
};
```

**Преимущества:**
- Автоматическое управление памятью
- RAII паттерн - сама память очищается
- Гарантирует существование объекта

**Когда вызываются конструкторы:**
1. Создаётся Circle_WithObject
2. В списке инициализации создаются center и color
3. Выполняется тело конструктора

#### Композиция с указателем:
```cpp
class Circle_WithPointer {
private:
    Point *center;     // Указатель (динамический объект)
public:
    Circle_WithPointer() {
        center = new Point();  // Создание в конструкторе
    }
    ~Circle_WithPointer() {
        delete center;         // Удаление в деструкторе
    }
};
```

**Преимущества:**
- Гибкость (можно менять объект)
- Может быть nullptr

**Недостатки:**
- Нужно ручное управление
- Если забыть delete - утечка памяти
- Опасно: double-delete

**Примеры в файле:**
- Композиция с объектом (статический)
- Композиция с указателем (динамический)
- Порядок вызова конструкторов/деструкторов
- Удаление композируемых объектов
- Сравнение двух подходов

**Запуск:**
```bash
g++ -o composition 04_composition.cpp
./composition
```

### 6. `05_assignment_and_copying.cpp` - Присваивание и копирование
**Что изучаем:** Что происходит при копировании объектов и указателей

#### Копирование объектов (значения):
```cpp
Square sq1(5.0);
Square sq2 = sq1;  // Конструктор копирования

// После этого:
sq1.setSide(10.0);
// sq2 НЕ изменился - они независимы!
```

Каждый объект имеет свои КОПИИ значений.

#### Копирование указателей:
```cpp
Square *ptr1 = new Square(3.0);
Square *ptr2 = ptr1;  // Копирование указателя

// После этого:
ptr1->setSide(15.0);
// ptr2 ИЗМЕНИЛСЯ - один объект!
```

Оба указателя указывают на ОДИН объект.

#### Конструктор копирования для объектов с динамической памятью:
```cpp
Rectangle(const Rectangle& other) {
    data = new double[100];    // НОВЫЙ блок памяти!
    data[0] = other.data[0];
}
```

Без этого произойдёт проблема: две стрелки на один блок памяти.

**Примеры в файле:**
- Копирование простого объекта
- Независимость копий
- Копирование указателя (общий объект)
- Проблема dangling pointer
- Конструктор копирования для динамической памяти
- Присваивание (оператор =)
- Срезание объекта при присваивании к базовому классу

**Запуск:**
```bash
g++ -o assignment 05_assignment_and_copying.cpp
./assignment
```

### 7. `06_method_override.cpp` - Переопределение методов
**Что изучаем:** Как наследник меняет поведение методов базового класса (БЕЗ virtual)

```cpp
class Shape {
public:
    void describe() { cout << "Это фигура"; }
};

class Circle : public Shape {
public:
    void describe() { cout << "Это круг"; }  // ПЕРЕОПРЕДЕЛЕНИЕ
};
```

**ВАЖНО: БЕЗ `virtual` компилятор использует тип УКАЗАТЕЛЯ:**
```cpp
Shape *s = new Circle();
s->describe();  // Вызовет Shape::describe (НЕ Circle!)
```

**Примеры в файле:**
- Базовый класс с методами
- Наследник 1 со своей реализацией
- Наследник 2 со своей реализацией
- Наследник БЕЗ переопределения (использует базовый)
- Статические объекты вызывают правильные методы
- Указатель базового класса вызывает методы базового класса
- Массив указателей на разные наследники
- Специфичные методы (не работают через базовый указатель)
- Приведение типов

**Запуск:**
```bash
g++ -o override 06_method_override.cpp
./override
```

## 🔍 Как читать отладочный вывод

Каждая программа выводит:
- **[ClassName конструктор]** - конструктор вызван
- **[ClassName деструктор]** - деструктор вызван
- Параметры создания
- Текущее состояние объекта

Это помогает понять порядок создания/удаления объектов.

**Пример:**
```
[Shape конструктор] Базовый класс создан: name=Shape
[Rectangle конструктор] Наследник создан: width=3, height=4
[Rectangle деструктор] Наследник удален: width=3, height=4
[Shape деструктор] Базовый класс удален: name=Shape
```

Видим: вход → базовый конструктор → наследник конструктор → наследник деструктор → базовый деструктор

## 📚 Справочная информация

### Оператор scope resolution (::)
```cpp
class Shape {
    void describe() { }
};

class Circle : public Shape {
    void describe() { 
        Shape::describe();  // Вызвать метод базового класса
    }
};
```

### Список инициализации
```cpp
Circle(double r) : radius(r), count(0) { }
// Правильно! radius инициализирован ПЕРЕД телом конструктора
```

### Const в конструкторе копирования
```cpp
Circle(const Circle& other) { }
// const - не изменяем копируемый объект
// & - передаём ссылку, а не копию
```

### Приведение типов
```cpp
Shape *s = new Circle();
Circle *c = (Circle *)s;     // C-style cast
Circle *c = dynamic_cast<Circle*>(s);  // C++ style (безопаснее)
```
