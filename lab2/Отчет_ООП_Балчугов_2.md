### 3.1 access_levels_demo.cpp - PRIVATE, PROTECTED, PUBLIC

#### Что изучаем
Уровни доступности членов класса и инкапсуляция данных.

#### Ключевые концепции

| Уровень доступа | В классе | В наследнике | Снаружи | Применение |
|---|---|---|---|---|
| **PRIVATE** | ✓ | ✗ | ✗ | Внутренние данные, скрытые от внешнего доступа |
| **PROTECTED** | ✓ | ✓ | ✗ | Данные для наследников, скрыты от клиентов |
| **PUBLIC** | ✓ | ✓ | ✓ | Открытый интерфейс класса |

#### Практический пример
```cpp
class Person {
private:
    string ssn;              // Социальный номер - конфиденциально
    
protected:
    string name;             // Может быть использовано наследником
    
public:
    string department;       // Открыто для всех
    
    void DisplayInfo() {     // public метод
        cout << ssn << name; // Может обращаться к private/protected
    }
};
```

#### Примеры в программе
- ✓ Обращение к public полям
- ✗ Ошибка при обращении к private полям
- Использование protected в наследниках
- Инкапсуляция (private данные + public методы для доступа)
- Практические примеры утечки инкапсуляции

#### Результат выполнения
Демонстрация ошибок компиляции при нарушении уровней доступности.

### 3.2 01_static_and_dynamic.cpp - Статические и динамические объекты

#### Что изучаем
Создание объектов в стеке (статические) и в куче (динамические), управление памятью.

#### Ключевые концепции

**Статические объекты (в стеке):**
```cpp
Point p1;              // Объект создается в стеке
Point p2(3.5, 4.2);   // С параметрами
                       // Автоматически удаляется в конце блока
```

**Динамические объекты (в куче):**
```cpp
Point *p3 = new Point();        // Создание динамического объекта
Point *p4 = new Point(5.5, 6.2);
delete p3;                       // ОБЯЗАТЕЛЬНО удалить!
delete p4;
```

#### Сравнение статических и динамических объектов

| Характеристика | Статический | Динамический |
|---|---|---|
| Синтаксис создания | `Point p;` | `Point *p = new Point();` |
| Память | Стек | Куча |
| Время жизни | До конца блока (автоматическое) | До `delete` (ручное управление) |
| Обращение к методам | `p.method()` | `p->method()` |
| Получение адреса | `&p` | `p` (сам указатель) |
| Размер памяти | Заранее известен | Может быть переменным |
| Производительность | Быстрее | Медленнее (управление памятью) |

#### Примеры в программе
- Создание объектов в стеке с выводом адресов
- Создание объектов в куче с выводом адресов
- Разница в обращении к полям (`.` vs `->`)
- Демонстрация проблемы утечки памяти
- Правильное удаление динамических объектов

#### Результат выполнения
```
Статические объекты в стеке:
Point p1: адрес = 0x7ffee...
Point p2: адрес = 0x7ffee...

Динамические объекты в куче:
Point p3: адрес = 0x10e41...
Point p4: адрес = 0x10e51...

Объект удален из куче (вызван деструктор)
```

### 3.3 02_constructors_destructors.cpp - Конструкторы и деструкторы

#### Что изучаем
Жизненный цикл объектов: создание, инициализация, удаление.

#### Жизненный цикл объекта

```
1. РОЖДЕНИЕ (создание)
   ↓
2. КОНСТРУКТОР (инициализация)
   ↓
3. ЖИЗНЬ (использование)
   ↓
4. ДЕСТРУКТОР (очистка)
   ↓
5. СМЕРТЬ (удаление)
```

#### Типы конструкторов

1. **Конструктор по умолчанию** (no-arg constructor)
```cpp
Circle()  // Без параметров
```

2. **Конструктор с параметрами** (parametrized constructor)
```cpp
Circle(double r)  // С параметрами
```

3. **Конструктор копирования** (copy constructor)
```cpp
Circle(const Circle& other)  // Копирование объекта
```

4. **Деструктор** (destructor)
```cpp
~Circle()  // Вызывается при удалении
```

#### Порядок вызова конструкторов/деструкторов

**Для статического объекта:**
```cpp
{
    Circle c1;           // → Конструктор по умолчанию
    Circle c2(5.0);      // → Конструктор с параметром
    Circle c3 = c2;      // → Конструктор копирования
}   // → Деструкторы c3, c2, c1 (в обратном порядке)
```

**Для динамического объекта:**
```cpp
Circle *c = new Circle();  // → Конструктор
delete c;                   // → Деструктор
```

#### Примеры в программе
- Конструктор по умолчанию с отладочным выводом
- Конструктор с параметрами
- Конструктор копирования
- Деструктор с информацией об удалении
- Порядок вызова в разных сценариях
- Чтение отладочного вывода для понимания жизненного цикла

#### Результат выполнения
```

  Circle constructor (default)
Создание c2(5.0):
  Circle constructor (5.0)
Копирование c3 = c2:
  Circle copy constructor
Конец блока:
  Circle destructor
  Circle destructor
  Circle destructor
```

### 3.4 03_inheritance.cpp - Наследование и иерархия классов

#### Что изучаем
Создание иерархия классов, наследование функциональности, порядок вызовов конструкторов/деструкторов в иерархии.

#### Базовый класс и наследник

```cpp
class Shape {              // Базовый класс (родитель)
public:
    Shape() { ... }
    virtual void draw() { ... }
    virtual ~Shape() { ... }
};

class Rectangle : public Shape {  // Наследник (потомок)
public:
    Rectangle() : Shape() { ... }  // Вызов конструктора базового класса
    void draw() override { ... }   // Переопределение метода
    ~Rectangle() { ... }
};
```

#### Порядок вызова конструкторов и деструкторов

**При создании объекта наследника:**
```
Rectangle rect;
  ↓
1. Конструктор Shape (базовый класс)
  ↓
2. Конструктор Rectangle (наследник)
```

**При удалении объекта наследника:**
```
delete rect;
  ↓
1. Деструктор ~Rectangle (наследник)
  ↓
2. Деструктор ~Shape (базовый класс)
```

**ВАЖНО:** Порядок деструкторов ОБРАТЕН порядку конструкторов!

#### Иерархия может быть многоуровневой

```
Shape (базовый)
  ├── Rectangle
  ├── Circle
  └── Triangle
```

#### Проблема срезания (object slicing)

```cpp
Rectangle rect(10, 20);
Shape shape = rect;  // ОПАСНО! rect срезается до Shape
// shape содержит только данные Shape, потеряны данные Rectangle
```

#### Примеры в программе
- Объект базового класса
- Объект наследника
- Наследник БЕЗ явного конструктора (использует базовый)
- Указатель базового класса на объект наследника
- Демонстрация срезания (object slicing)
- Порядок вызова конструкторов/деструкторов
- Множественное наследование (если присутствует)

#### Результат выполнения
```

  Shape constructor
Создание Rectangle(10, 20):
  Shape constructor
  Rectangle constructor
Создание Circle(5):
  Shape constructor
  Circle constructor
Удаление:
  Rectangle destructor
  Shape destructor
  Circle destructor
  Circle destructor
```

### 3.5 04_composition.cpp - Композиция объектов

#### Что изучаем
Использование объектов один внутри другого (композиция), разница между имением объекта и имением указателя на объект.

#### Композиция через объект

```cpp
class Circle {
private:
    Point center;        // Объект (НЕ указатель)
    double radius;
    
public:
    Circle(double x, double y, double r)
        : center(x, y), radius(r) { }  // Список инициализации
};
```

**Порядок создания при инициализации:**
1. Создается объект Circle
2. В списке инициализации создается Point center
3. Выполняется тело конструктора Circle

**Удаление:** Автоматическое при удалении Circle.

#### Композиция через указатель

```cpp
class Circle {
private:
    Point *center;       // Указатель (динамический объект)
    double radius;
    
public:
    Circle() {
        center = new Point();  // Ручное создание
    }
    ~Circle() {
        delete center;         // Ручное удаление!
    }
};
```

**Удаление:** Ручное в деструкторе через `delete`.

#### Сравнение двух подходов

| Аспект | Объект (композиция) | Указатель (агрегация) |
|--------|---|---|
| Создание | Автоматическое | Ручное (в конструкторе) |
| Память | RAII паттерн | Управление памятью |
| Удаление | Автоматическое | Ручное (в деструкторе) |
| Гибкость | Меньше | Больше (nullptr) |
| Безопасность | Выше | Требует внимания |
| Производительность | Быстрее (нет new/delete) | Медленнее |

#### Примеры в программе
- Класс Circle с объектом Point (композиция)
- Класс Circle с указателем Point (агрегация)
- Порядок вызова конструкторов/деструкторов
- Переинициализация объектов в заново созданном объекте
- Демонстрация утечки памяти при неправильному управлению
- Правильное использование списка инициализации

#### Результат выполнения
```

  Point constructor
  Circle constructor
Удаление:
  Circle destructor
  Point destructor

Создание Circle с указателем Point:
  Point constructor (через new)
  Circle constructor
Удаление:
  Circle destructor
  Point destructor (через delete)
```

### 3.6 05_assignment_and_copying.cpp - Присваивание и копирование

#### Что изучаем
Поведение при копировании объектов, конструктор копирования, проблемы shallow copy vs deep copy.

#### Копирование объектов (значения)

```cpp
Square sq1(5.0);
Square sq2 = sq1;  // Конструктор копирования

sq1.setSide(10.0);
cout << sq2.getSide();  // Выведет 5.0 - независимый объект
```

Каждый объект имеет независимые копии членов.

#### Копирование указателей

```cpp
Square *ptr1 = new Square(3.0);
Square *ptr2 = ptr1;  // НЕ копирование, общий объект

ptr1->setSide(15.0);
cout << ptr2->getSide();  // Выведет 15.0 - один объект!
```

Оба указателя указывают на ОДИН и ТОТ ЖЕ объект.

#### Shallow Copy vs Deep Copy

**Shallow Copy (неглубокое копирование):**
```cpp
// Проблема: две переменные указывают на одну память
Rectangle r1;
r1.data = new double[100];

Rectangle r2 = r1;  // Shallow copy - data указывает на ту же память!

delete r1;  // Освобождение памяти
// r2.data теперь указывает на удаленную память (dangling pointer)
```

**Deep Copy (глубокое копирование):**
```cpp
Rectangle(const Rectangle& other) {
    data = new double[100];           // НОВАЯ память
    for (int i = 0; i < 100; i++)
        data[i] = other.data[i];      // Копирование значений
}
```

Каждый объект имеет свой блок памяти.

#### Dangling Pointer (висячий указатель)

```cpp
Rectangle *a = new Rectangle();
Rectangle *b = a;  // Оба указывают на один объект

delete a;  // Удаление объекта
b->print();  // ОШИБКА! b->data指向удаленную память
```

#### Срезание объекта (object slicing)

```cpp
Rectangle rect(5, 10);
Shape shape = rect;  // Срезание: часть данных потеряна

// shape содержит только данные Shape
// Информация об ширине/высоте Rectangle потеряна
```

#### Примеры в программе
- Копирование простых объектов
- Проверка независимости копий
- Копирование указателей (общий объект)
- Проблема dangling pointer
- Конструктор копирования для объектов с динамической памятью
- Операторор присваивания (=)
- Срезание объекта при присваивании к базовому классу
- Проблема double deletion

#### Результат выполнения
```

  Square copy constructor
  sq1.side = 10.0
  sq2.side = 5.0  (независимый объект)

Копирование указателей:
  ptr1->side = 15.0
  ptr2->side = 15.0  (один объект!)
```

### 3.7 06_method_override.cpp - Переопределение методов

#### Что изучаем
Как наследник может переопределить методы базового класса БЕЗ использования `virtual` (статическое связывание).

#### Без виртуальных методов (статическое связывание)

```cpp
class Shape {
public:
    void draw() { cout << "Shape draw"; }
};

class Circle : public Shape {
public:
    void draw() { cout << "Circle draw"; }  // Переопределение
};
```

**Какой метод вызывается?**
```cpp
Circle c;
c.draw();  // Выведет "Circle draw"

Shape *s = &c;
s->draw();  // Выведет "Shape draw"  ← Статическое связывание!
```

Метод выбирается по типу указателя/ссылки, НЕ по типу объекта!

#### С виртуальными методами (динамическое связывание)

```cpp
class Shape {
public:
    virtual void draw() { cout << "Shape draw"; }
};

class Circle : public Shape {
public:
    void draw() override { cout << "Circle draw"; }  // Переопределение
};
```

**Какой метод вызывается?**
```cpp
Circle c;
c.draw();  // Выведет "Circle draw"

Shape *s = &c;
s->draw();  // Выведет "Circle draw"  ← Динамическое связывание!
```

Метод выбирается по типу объекта, независимо от типа указателя/ссылки!

#### Таблица: Статическое vs Динамическое связывание

| Сценарий | Статическое (БЕЗ virtual) | Динамическое (С virtual) |
|---|---|---|
| `Circle c; c.draw();` | Circle draw | Circle draw |
| `Shape *s = &c; s->draw();` | Shape draw | Circle draw |
| `Shape &s = c; s.draw();` | Shape draw | Circle draw |
| Выбор метода | По типу переменной | По типу объекта |
| Когда определяется | На этапе компиляции | На этапе выполнения |
| Производительность | Быстрее | Медленнее (таблица virtual) |

#### Примеры в программе
- Классы Shape, Circle, Rectangle
- Методы без `virtual` (статическое связывание)
- Переопределение методов в наследниках
- Вызов через указатель базового класса
- Демонстрация разницы в выборе метода
- Возможные ошибки и недоразумения

#### Результат выполнения
```
Статическое связывание (без virtual):
Circle c; c.draw() → Circle::draw()
Shape *s = &c; s->draw() → Shape::draw()  (НЕОЖИДАННО!)

Рекомендация: Используйте 'virtual' для переопределяемых методов!
```

## 4. Ключевые концепции ООП

### 4.1 Инкапсуляция (Encapsulation)
- **Определение:** Скрытие внутренних деталей реализации от внешнего мира
- **Уровни доступности:** PRIVATE, PROTECTED, PUBLIC
- **Преимущества:** Безопасность, контроль, гибкость
- **Пример:** Класс Person с private данными и public методами

### 4.2 Наследование (Inheritance)
- **Определение:** Создание новых классов на основе существующих
- **Базовый класс:** Shape (родитель)
- **Наследник:** Rectangle, Circle (потомки)
- **Порядок инициализации:** Базовый класс → Наследник
- **Порядок удаления:** Наследник → Базовый класс

### 4.3 Полиморфизм (Polymorphism)
- **Статический:** Выбор методов по типу переменной (без virtual)
- **Динамический:** Выбор методов по типу объекта (с virtual)
- **Виртуальные методы:** Позволяют переопределение в наследниках
- **Override:** Правильный способ переопределения

### 4.4 Композиция (Composition)
- **Определение:** Использование объектов внутри других объектов
- **Объект:** Автоматическое управление памятью (RAII)
- **Указатель:** Ручное управление памятью (new/delete)
- **Список инициализации:** Правильный способ инициализации

## 5. Важные моменты и ловушки

### 5.1 Управление памятью
```cpp
// ✓ ПРАВИЛЬНО
Point *p = new Point();
// ... использование ...
delete p;

// ✗ НЕПРАВИЛЬНО
Point *p = new Point();
// забыли delete → утечка памяти!
```

### 5.2 Виртуальный деструктор
```cpp
// ✓ ПРАВИЛЬНО
class Shape {
public:
    virtual ~Shape() { }  // Виртуальный деструктор
};

// ✗ НЕПРАВИЛЬНО
class Shape {
public:
    ~Shape() { }  // Нет virtual
};
Shape *s = new Circle();
delete s;  // Не вызовется деструктор Circle!
```

### 5.3 Конструктор копирования для динамической памяти
```cpp
// ✓ ПРАВИЛЬНО
Rectangle(const Rectangle& other) {
    data = new double[size];
    copy(other.data, other.data + size, data);
}

// ✗ НЕПРАВИЛЬНО - shallow copy
Rectangle(const Rectangle& other) {
    data = other.data;  // Обе переменные указывают на одну память!
}
```

### 5.4 Список инициализации
```cpp
// ✓ ПРАВИЛЬНО - до выполнения тела конструктора
Circle() : center(0, 0), radius(0) { }

// ✗ НЕПРАВИЛЬНО - присваивание в теле
Circle() { center = Point(0, 0); radius = 0; }
```

### 5.5 Срезание объекта (object slicing)
```cpp
// ✓ ПРАВИЛЬНО - используйте указатели/ссылки
Shape *s = new Circle();

// ✗ ОПАСНО - срезание
Shape s = circle;  // Потеря данных!
```
